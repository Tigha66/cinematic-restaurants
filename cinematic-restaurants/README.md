# Cinematic Restaurant Concepts

Five cinematic, scroll-driven concept redesigns:

- `/manze` — M. Manze
- `/bocca` — Bocca di Lupo
- `/andrew-edmunds` — Andrew Edmunds
- `/rules` — Rules
- `/tayyabs` — Tayyabs

Tech:

- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion (scroll-driven motion)
- React Three Fiber + drei (3D mark)

## Run locally

```bash
npm i
npm run dev
```

## Deploy to Vercel

- Import the `cinematic-restaurants` folder as a new project in Vercel.
- Framework preset: **Next.js** (auto-detected)
- Build command: `next build` (default)
- Output: `.next` (default)

This repo is concept/demo work and not affiliated with the restaurants.
